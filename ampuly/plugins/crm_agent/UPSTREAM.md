# Sales CRM source and adaptation

Source: https://github.com/kargulstudio/sales-crm

Commit: 2bb85561794d21d2af67aa7c366f40ec1ef961ee (2026-10-06), package 0.1.0.

The company list/filter/search/detail and creation interaction structure informed the React workbench. This implementation adapts that interaction to the engine's React/Vite/CSS and server authority. It does not copy Next.js, Tailwind globals, demo records, scores, fake activities, logos, avatars or fonts. No new dependency was introduced.
