Ampuly Observatory Orb - source and implementation notice

The native WebGL renderer (orbRenderer.ts) and React lifecycle wrapper
(OrbCanvas.tsx) were newly written for Ampuly. No Three.js runtime, remote
asset, installer, Brain database, or user-level MCP configuration is required.

Visual inspiration: Jarvis Orb, TheStack-ai (formerly whynowlab), specifically
its Fresnel-lit sphere, procedural surface movement, and activity-driven orb
presentation. This is visual inspiration and an independent implementation;
the GLSL/renderer is not represented as upstream Three.js code.

Representation boundary:
The visualizer depicts supplied execution status; it does not expose hidden
model chain-of-thought. A satellite is a capped visual representation of the
supplied actor count, not proof of independent agent execution. Failed/review
states persist until upstream facts change. Disconnected rendering is grey
and stationary. Static rendering is available for reduced motion and GPU loss.
