# Synthetic isolation-planning examples

These files are newly authored public samples. They contain no customer workflow,
account, credential, conversation or production data.

`sample-clean.txt` is inert text. `clean-params-template.json` describes a planning
record, and mirrors the static template returned by the admission module. A null
hash or timestamp is unrecorded, not a successful verification.

The template does not authorize installation, MCP registration, hardening,
restoration or product data access. All corresponding execution guards remain in
force. No model or external tool needs to run to read these files.
